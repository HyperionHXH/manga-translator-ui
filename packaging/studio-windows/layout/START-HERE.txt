Manga Studio for Windows (x64 CPU portable)
==========================================

START
  Double-click MangaStudio.exe.
  No installer, .bat file, system Python, or external runtime is used.
  The launcher starts packaging\python\pythonw.exe with
  desktop_qt_ui\main.py from this folder.
  In the control center, click Start Core, then Open Translation Workspace.
  Stop Core waits for the current batch; Stop Task requests cancellation.

REQUIREMENTS
  - 64-bit Windows 10 or Windows 11.
  - Keep the whole folder together. Do not move MangaStudio.exe alone.
  - Use a writable folder. Avoid Program Files, read-only media, and
    cloud-synced folders if the application cannot create config or result
    files. First launch creates config\config.json, .env, result\, and model
    caches inside this folder.
  - Back up config\, .env, result\, and downloaded models before replacing
    program files with a newer build.

WHAT IS INCLUDED
  - Native GUI launcher: MangaStudio.exe
  - Bundled Python 3.12 runtime: packaging\python\
  - uv package manager for optional maintenance: packaging\uv.exe
  - Default offline CPU models in models\: text detection, LaMa Large
    ONNX with its PyTorch fallback, 48px/CTC OCR, and Chinese/Korean PaddleOCR.
  - Optional PortableGit\ when this build included it.
  Additional models are downloaded by the application on first use.

STARTUP ERRORS
  pythonw.exe has no console window. The launcher captures stdout and stderr
  and shows a message box for a non-zero exit code or an uncaught Python
  startup traceback. It never silently hides a startup failure.
  Read these files after an error:
    result\launcher_*.log
    result\log_*.txt
  The launcher waits for the application and returns its exit code. Close the
  application before replacing files.

COMMAND LINE
  Start normally:      MangaStudio.exe
  Launcher help:       MangaStudio.exe --studio-help
  Launcher version:    MangaStudio.exe --studio-version
  This build accepts no file paths or arbitrary application arguments. Only
  the reserved launcher flags are consumed; maintenance switches such as
  --maintenance, --auto-update, --resume-install, and --resume-update are
  rejected. No API keys, tokens, or environment values are passed as
  command-line arguments.
  Only one instance can run from a distribution folder at a time, so two
  windows cannot race on the same config\ and result\ files.

UPDATES
  This distribution is built from the fork's Git-tracked source and does not
  include a .git checkout. In-app Git source updates are therefore not
  available. Install newer fork builds by replacing the program files while
  preserving config\, .env, result\, and any downloaded models you want to
  keep.

中文快速开始
  双击 MangaStudio.exe 启动。无需安装，不使用 BAT，也不依赖系统 Python。
  在控制中心点击「启动核心」，再进入翻译工作台。「停止核心」等待正在处理的
  批次；要取消当前任务，使用「停止任务」。
  请保持整个文件夹完整，不要单独移动 EXE；请放在可写目录（不要放在只读
  位置或权限受限的 Program Files 下）。首次启动会在本目录创建
  config\config.json、.env、result\ 等文件，升级前请先备份。
  同一目录只允许运行一个实例，避免两个窗口同时修改 config\ 和 result\。
  本版本不接受文件路径或任意命令行参数，也不会把密钥/令牌作为参数传入。
  启动失败时会弹窗，不会静默闪退；请查看 result\launcher_*.log 和
  result\log_*.txt。
  模型许可见 LICENSES\MODELS.md：观测到的模型仓库许可为 CC-BY-NC-4.0，
  部分可选模型（如 MangaJaNai / IllustrationJaNai）仅限非商业使用；各上游
  模型自身条款仍然适用。
